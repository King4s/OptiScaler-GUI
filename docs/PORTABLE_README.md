# Portable Rust app

Download the native EXE or the 7z containing the same EXE from [GitHub Releases](https://github.com/King4s/OptiScaler-GUI/releases/latest). See the [2026.11.0 release notes](releases/2026.11.0.md) for changes.
Run it in a writable folder; cache/config/log files are stored beside the executable.
No Python installation or bundled Python runtime is required. Runtime archive extraction is pure Rust.
See [hardware/runtime guide](hardware-runtime.md) for the 2026.10.0 startup and opt-in RDNA2 changes.
Available downloads and their exact feature scope are determined by GitHub Releases, not this source checkout.
