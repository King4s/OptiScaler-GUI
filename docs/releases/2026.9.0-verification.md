## Additional evidence and limits

- Dependency audit reported zero vulnerabilities and the existing unmaintained `ttf-parser` warning.
- Read-only local store smoke found Ubisoft: 2, Amazon: 0, EA: 0, Battle.net: 0, with 3 warnings total. Ubisoft has positive live discovery evidence. The other adapters have fixture coverage, not positive live discovery evidence; warning details were not supplied here.
- Startup smoke does not verify visual translations or gameplay. Real-game install/update/uninstall and the Fatekeeper overlay were not exercised.
- Authenticated SteamGridDB testing was not performed because no API key was available. Automated coverage does not establish a successful live authenticated flow.
- SteamGridDB lookup sends an explicit Steam app ID when available, or a title for search, after consent. The user chooses the game and image.
- Fatekeeper's working user report from 2026-09-25 remains valid. A missing fresh-version retest is not evidence of failure or a special publication blocker.
- Discovery is best effort; neither all-game discovery nor universal OptiScaler compatibility is claimed.
- This scope adds no mods and changes no installer behavior. Target, ownership, rollback and legacy/foreign-file safety remains in force.
- Historical beta evidence applies to its own tree and remains unchanged.
