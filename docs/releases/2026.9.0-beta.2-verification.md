## Manual checks still open

- Fatekeeper: exact GPU/driver, GUI/game/OptiScaler versions, selected EXE/proxy target,
  loaded overlay and real-game install/update/uninstall results.
- Hands-on packaged-app rollback and legacy-install recovery on representative games.
- Visual translation/layout review; startup with a language setting is not visual QA.

Synthetic resolver, transaction and privacy tests pass; they do not establish runtime
compatibility for every game. No real game files were changed during packaging or smoke.
This record does not authorize a stable release or claim that beta.2 is public.

To repeat the candidate build, stage the intended source and run
`scripts/build-beta-candidate.ps1 -TargetDirectory <isolated-target> -OutputDirectory <new-output>`.
It records a Git source tree and source archive before compiling, refuses source changes
during the build, and writes EXE, 7z, SHA256SUMS.txt and verification.json. Only the
first three are distribution assets; local smoke folders and logs are not for upload.
