# OptiScaler GUI 2026.9.0 Standard

2026.9.0 expands installed-game discovery and gives you more control over library artwork.

## Discovery

- Adds Amazon Games discovery from local SQLite, Ubisoft Connect from registry metadata, EA app/Origin from registry and installerdata XML, and Battle.net from its local product database.
- Adds configurable library folders with enable/disable, remove and rescan controls. Removing a scan root never deletes games.
- Retains Steam, Epic, GOG, Heroic, Xbox and manual discovery, with path-based deduplication and separate store identity and title provenance.

Discovery depends on available metadata and existing install paths. Some games or layouts may be missed; use a specific library folder or manual selection when needed. See [supported formats and limits](https://github.com/King4s/OptiScaler-GUI/blob/v2026.9.0/docs/store-formats.md).

## Artwork

- Fits covers without stretching or cropping their aspect ratio.
- Uses per-install cache keys, preserves legacy artwork files and allows identified Steam portraits to upgrade landscape artwork.
- Adds cover source display, local image selection, reset and refresh controls. Refresh preserves explicitly selected covers and retains the last good artwork if replacement fails.
- Adds optional SteamGridDB lookup with explicit consent and a session-only user API key. Lookup sends an explicit Steam app ID when available, or a title for search; you choose the matching game and image.
- Keeps automatic SteamGridDB requests disabled and removes automatic SteamSpy title matching from the artwork path.

Identified store/Steam artwork can still use network downloads. SteamGridDB credentials are not saved or sent with image downloads. See [artwork and privacy details](https://github.com/King4s/OptiScaler-GUI/blob/v2026.9.0/docs/cover-art.md).

## Compatibility and safety

This release adds no mods and changes no installer behavior. Reviewed targets, explicit executable selection for ambiguous layouts, ownership checks, rollback and preservation of legacy/foreign files remain in place. Discovery and artwork do not establish OptiScaler compatibility.

Fatekeeper has a working user report; no fresh-version gameplay or manual visual test is claimed. Authenticated SteamGridDB testing was not performed because no API key was available.

See [troubleshooting](https://github.com/King4s/OptiScaler-GUI/blob/v2026.9.0/docs/TROUBLESHOOTING.md) and the [verification record](https://github.com/King4s/OptiScaler-GUI/blob/v2026.9.0/docs/releases/2026.9.0-verification.md) for evidence and limitations.
