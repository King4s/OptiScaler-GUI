# OptiScaler-GUI 2026.9.0-beta.2 Standard

**Prerelease candidate, not publicly released.** These notes describe the locally assembled candidate, not a published artifact or a stable compatibility claim. Back up game files before testing. Online and anti-cheat games may block injection or impose account penalties; the GUI does not disable anti-cheat.

## Changes since beta.1

- Game scans deduplicate by normalized install path, not by title or store ID. Repeated hits for one install merge, retaining available store identity and artwork; same-title installs at different paths remain separate. Identity comes from observed store metadata and does not authorize an install.
- Discovery provenance and title provenance are distinct. A store-supplied title can replace a folder-derived title for the same install without dropping the other hit's identity.
- Path keys fold case, `/` versus `\`, and a trailing separator. They do not lexically fold `.` or `..` or resolve symlinks/junctions. Existing GPU choices can fall back to the prior key; no settings rewrite is claimed.
- For uncached Steam games, artwork tries the exact-app-ID local Steam library portrait, then the GetItems portrait, followed by the existing CDN header and appdetails fallbacks. Existing cached images remain preferred, including landscape images; there is no cache migration or automatic image replacement.
- The appdetails fallback accepts a response under any object key only when both its `data.steam_appid` and image URL path match the requested app ID. If the header cannot be used, the capsule remains a fallback. Invalid or mismatched artwork is skipped rather than attributed to another game.

No new store scanners or SteamGridDB integration are included. Existing install-target review, v2 ownership safeguards, local guidance, and explicit report preview/export remain as described in the [beta.1 notes](2026.9.0-beta.1.md). A scan result or cover is not a game compatibility guarantee.

## Validation and limits

- PRs #33, #34 and #35 were independently green but are not merged. The candidate combines their changes with the appdetails-art guard. Combined local formatting, Clippy, workspace tests, release build, 7z integrity/extraction and da/en/pl startup smoke passed on 2026-10-02. See [verification and checksums](2026.9.0-beta.2-verification.md). This is not manual gameplay or visual translation verification.
- Manual Fatekeeper verification with exact hardware, game and OptiScaler versions, overlay result, and real-game install/update/uninstall was not performed in this run. The earlier user report of Fatekeeper working does not fill those gaps or establish broader compatibility.
- Hands-on packaged-app install, update, rollback and uninstall, including legacy-install safety, and representative game-layout checks remain pending. Legacy installs without a complete owned-file manifest are not automatically migrated or removed.

Do not treat these notes as download instructions until the coordinator has completed validation and published an artifact. The app obtains OptiScaler from official releases when installing; the GUI does not bundle its payload or extra mods. Report GUI issues to this repository, not to the OptiScaler developers. Do not copy code from foreign reference repositories into this project.
