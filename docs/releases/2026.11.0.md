# OptiScaler-GUI 2026.11.0

Stable portable release for Windows 10/11. Download **OptiScaler-GUI.exe** to run the app directly, or extract **OptiScaler-GUI.7z** for the same executable. **SHA256SUMS.txt** covers both downloads.

## What's new

- Steam cards prefer wide images from the game's local Steam cache and keep their original proportions. Manually selected covers are preserved.
- The library opens with **Likely compatible** enabled. Select **Show all games** to see the full library; the GUI remembers your choice. The shortlist is not a guarantee of support.
- Interrupted release downloads no longer leave a partial archive. The installer checks previously extracted files and repairs missing or changed DLLs before reuse.
- **Restore defaults** uses the exact OptiScaler version recorded for the game. Cached defaults work offline; if the matching defaults are unavailable, the GUI does not substitute a newer version.
- With [OptiScaler v0.9.5](https://github.com/optiscaler/OptiScaler/releases/tag/v0.9.5), the editor shows the correct INT8 choices and contrast setting, and the GUI recognizes the initialization log marker. On supported RX 6000 GPUs, try the official FSR 4.1.2 runtime first; the older community runtime is optional.

The [Windows upgrade check](https://github.com/King4s/OptiScaler-GUI/actions/runs/44971702304) exercised a real v0.9.4-to-v0.9.5 upgrade, cache repair and uninstall in a disposable game folder. It did not test in-game rendering or overlay behavior.
