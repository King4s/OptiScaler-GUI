# OptiScaler GUI 2026.10.0

Native Rust Windows portable release. Download **OptiScaler-GUI.exe** directly or extract **OptiScaler-GUI.7z**. **SHA256SUMS.txt** contains checksums for both files. No Python runtime is required.

## Hardware guidance

- Fresh local hardware collection runs on a background worker at startup, including when update checks are disabled.
- Hardware-specific recommendations and manual refresh are visible across screens in English, Danish and Polish.
- Recommendations do not change settings or establish game compatibility. Selecting the actual per-game rendering GPU remains explicit; stale or failed hardware snapshots cannot authorize the community runtime.

## Optional RDNA2 FSR runtime

- Explicitly selected RX 6000 GPUs can opt into the separately downloaded, pinned community **FSR 4.1.1b INT8 with RDNA2 fix**.
- Every operation requires consent. The app verifies archive and DLL SHA-256, uses separate cache/staging, and records provenance without modifying the official OptiScaler extraction.
- Guarded manual updates, restoration of the official runtime and uninstall preserve file ownership and original-file backups. Automatic updates do not silently replace community installations.
- Newer AMD GPUs keep the official runtime. Avoid games with anti-cheat; this community modification is not an official AMD release and compatibility is not guaranteed.

## Rust-only repository

The obsolete Python implementation, PyInstaller tooling and Python CI have been removed. Shared translations and game data are now owned by the Rust workspace. README, build/release instructions and feature documentation have been updated; historical releases remain available.

## Verification and limits

The feature was independently reviewed. Windows workspace tests, strict Clippy and formatting passed. Two real-artifact tests verified installation, update, official restoration, uninstall, cache repair and preservation on corruption in disposable game folders. Native startup was exercised in da/en/pl.

No gameplay, measured rendering quality/performance, anti-cheat safety, or live community-download compatibility guarantee is claimed. The release does not bundle OptiScaler or the community DLL; these are downloaded separately when selected.
