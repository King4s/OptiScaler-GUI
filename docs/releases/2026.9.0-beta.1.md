# OptiScaler-GUI 2026.9.0-beta.1 Standard

This is a **beta prerelease**, not the stable 2026.9.0 release. Back up your game files before testing. Online and anti-cheat games may block injection or impose account penalties; the GUI does not disable anti-cheat.

## What's new

- Safer game EXE and installation-target selection, including Unreal Win64/WinGDK layouts and a Satisfactory-specific target. Ambiguous layouts require your choice and a confirmation preview.
- Ownership-aware install, update and uninstall with checksums, original-file backups and rollback. Modified binaries and foreign update collisions stop the operation; edited OptiScaler INI files are preserved.
- Local hardware inventory and source-linked, deterministic per-game guidance. Unknown games receive general guidance, not a compatibility guarantee.
- Separate installed, log-loaded and user-tested status; overlay troubleshooting; explicit INI change preview with backup.
- Opt-in JSON report preview and export. No telemetry or automatic upload; the export omits paths, filesystem-derived game names and raw logs.

Download either `OptiScaler-GUI.exe` directly or `OptiScaler-GUI.7z` containing the same EXE. Verify downloads with `SHA256SUMS.txt`. The app downloads OptiScaler from its official GitHub releases when you install it into a game; this release does not bundle the OptiScaler payload or extra mods.

**Known limits:** One user reported Fatekeeper working, but exact hardware, game/OptiScaler versions, overlay behavior and uninstall results were not recorded. This does not imply support for all games. Legacy installations without a complete GUI-owned manifest are not automatically migrated or removed. Please report game-specific results in this repository, not to the OptiScaler developers.
